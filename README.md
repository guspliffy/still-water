# Still Water

Drop stones on a dark pond. Ripples light the lanterns they touch, and gold lanterns light only where two rings meet.

Play: https://guspliffy.github.io/still-water/ (after GitHub Pages is enabled with Source "GitHub Actions").

```
npm install
npm run dev     # open the printed URL, or the Network URL on your phone
npm test
npm run build
```

Design: [docs/GDD.md](docs/GDD.md). Status: [docs/STATE.md](docs/STATE.md). Tuning panel: gear button, `T`, or `?dev`.
